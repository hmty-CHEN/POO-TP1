# Simulation d'un écosystème proie-prédateur

Projet de TP — Programmation orientée objet en Python.

> État actuel : exercices 1 à 10.

## Arborescence

```text
simulation-ecosysteme-poo/
├── animal.py
├── lapin.py
├── loup.py
├── main.py
├── rapport.html
├── traduction-rapport.md
└── docs/
    └── uml-exercices-1-a-10.md
```

| Fichier | Contenu |
| --- | --- |
| `animal.py` | Classe `Animal` (attributs et méthodes communs). |
| `lapin.py` | Classe `Lapin`, hérite d'`Animal`. |
| `loup.py` | Classe `Loup`, hérite d'`Animal`. |
| `main.py` | Création de plusieurs lapins. |
| `rapport.html` | Rapport de cours en français. |
| `traduction-rapport.md` | Traduction chinoise du rapport. |
| `docs/` | Diagramme UML. |

## Exécution

```bash
python main.py
python lapin.py
python loup.py
```

## Organisation du travail

1. Créer une branche par fonctionnalité.
2. Faire des commits courts et explicites.
3. Pousser la branche puis ouvrir une pull request.
