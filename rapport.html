Simulation d'un écosystème proie-prédateur

Rapport de TP — Exercices 1 à 6

1. Objectif

Cette première étape consiste à représenter un lapin par une classe Python simple, puis à manipuler plusieurs instances.

2. Analyse du lapin

AttributRôle
xPosition horizontale
yPosition verticale
energieÉnergie disponible
ageÂge du lapin
vitesseVitesse de déplacement

Les actions retenues sont se_deplacer, vieillir et est_vivant.

3. Réalisation

Le constructeur reçoit x et y. Les valeurs initiales sont une énergie de 100, un âge de 0 et une vitesse de 1.

se_deplacer(dx, dy) ajoute les déplacements aux coordonnées. vieillir() augmente l'âge de 1 et diminue l'énergie de 1. est_vivant() renvoie vrai si l'énergie est strictement positive.

4. Plusieurs instances

Cinq lapins sont stockés dans une liste. Une boucle permet de faire vieillir tous les objets. Cette organisation évite de répéter cinq fois le même code et permet de traiter la population collectivement.

5. Vérification

Quelques appels de vérification sont placés directement dans lapin.py : la création, le déplacement, le vieillissement et la mort. Ils affichent les valeurs attendues à l'exécution.

python lapin.py

6. Bilan

Les exercices 1 à 6 sont réalisés sans héritage ni classes supplémentaires. La conception restera volontairement simple jusqu'à l'introduction de ces notions dans les étapes suivantes.
